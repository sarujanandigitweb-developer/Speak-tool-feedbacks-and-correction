## **Business Logic Block**

**Purpose:** Define the rules that will govern classification, ordering and speech.

### **Rule 1 — Lampshade identification (replaces the keyword test)**

```
IF name matches ceiling-rose pattern
   THEN IF name also matches rectangle pattern THEN RECT_ROSE ELSE ROSE

ELSE IF name matches bulb pattern AND sku starts with 'LD'
   THEN BULB

ELSE IF sku starts with 'LS'
   THEN SHADE                     <-- name is NOT consulted

ELSE IF sku starts with 'LD'
   THEN BULB

ELSE OTHER
```

The ceiling-rose test stays first, so an `LS`-prefixed rose remains a rose. Wire cages (`WC*`)
carry no `LS` prefix and are excluded by construction.

### **Rule 2 — Conditional packing priority**

```
IF the order contains a Rectangle Ceiling Rose
   THEN rank: RECT_ROSE=1, SHADE=2, BULB=3, ROSE=4, OTHER=4
   ELSE rank: SHADE=1, ROSE=2, BULB=3, OTHER=4

Scan the WHOLE order for a Rectangle Ceiling Rose BEFORE sorting it.
Sort with a STABLE sort, WITHIN one customer's block only.
```

### **Rule 3 — Pipeline order**

```
Priority sorting MUST run AFTER addCombinedSKUSet().

addCombinedSKUSet() rebuilds "Combo SKU" by finding a "Combo: 1" marker and absorbing
the "Combo: 2", "Combo: 3" … rows that FOLLOW it, so it requires the original row order.
```

### **Rule 4 — Combo set boundary**

```
A component set starts at "Combo: 1" and continues ONLY while the row belongs to the
SAME customer. The set ends at a customer boundary even if the marker sequence continues.
```

### **Rule 5 — Queue grouping**

```
group_key = combined_SKU_string + customer_identity

The combined SKU string alone describes a PRODUCT SET, not an ORDER, so two customers
who buy the same kit must not collapse into one queue entry.
The card still DISPLAYS the SKU string alone.
```

### **Rule 6 — Speech segmentation**

```
one segment per component, in packing-priority order

advance to the next segment ONLY on an explicit Next
after the LAST component, append: Post Code, then Note
Post Code and Note are NOT separate steps — no extra Next is required
```

### **Rule 7 — Nothing may be silent**

```
IF the names sheet has a name        THEN speak the name
ELSE IF the row has a SKU            THEN speak "This one" + colour (if known)
ELSE                                  (open decision — see Open Decisions below)

Quantity is blanked ONLY when the row has neither a name nor a SKU.
```

### **Rule 8 — Colour authority**

```
colour = Lampshade SOT Outer_Colour
         ELSE Lampshade SOT Colour_Family
         ELSE SKU suffix lookup (ceiling roses, bulbs, accessories)

Where the SOT's Outer_Colour contradicts its OWN Product_Name, the product name wins
and the SKU is listed in an explicit override table. The list must not be extended by guessing.
```
