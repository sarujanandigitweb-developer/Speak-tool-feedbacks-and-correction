## **Business Logic Block**

**Purpose:** Define how products will be classified and ordered.

### **Rule 1 — Product classification (order of tests matters)**

```
IF name matches ceiling-rose pattern
   THEN IF name also matches rectangle pattern
        THEN product_type = RECT_ROSE
        ELSE product_type = ROSE

ELSE IF name matches bulb pattern AND sku starts with 'LD'
   THEN product_type = BULB

ELSE IF name matches shade pattern AND NOT accessory pattern
   THEN product_type = SHADE

ELSE IF sku starts with 'LD'
   THEN product_type = BULB

ELSE product_type = OTHER
```

**Ceiling rose must be tested first** because some `LS`-prefixed SKUs are ceiling roses, not
lampshades.

### **Rule 2 — Packing priority**

```
rank(SHADE)     = 1
rank(RECT_ROSE) = 2
rank(BULB)      = 3
rank(ROSE)      = 4
rank(OTHER)     = 4

Sort rows by rank using a STABLE sort, WITHIN one customer's block only.
Rows must never move between customers.
```

### **Rule 3 — Lampshade collection (colour-wise)**

```
IF total lampshade quantity < 15
   THEN collect exactly the required quantity per colour
IF total lampshade quantity >= 15
   THEN allocation rule is UNDEFINED — do not invent one, stop and report
Colours must NEVER be merged into a single quantity.
```

### **Rule 4 — Voice command handling**

```
normalise transcript (lowercase, strip punctuation, collapse whitespace)

IF word count > 5
   THEN ignore (prevents an ordinary sentence from navigating)

IF matched command = previous command AND elapsed < 1000 ms
   THEN ignore as duplicate
ELSE dispatch to the EXISTING controlSpeech(action) handler
```

### **Rule 5 — Microphone lifecycle**

```
IF user paused
   THEN never auto-restart
ELSE IF tool is speaking
   THEN keep microphone muted
ELSE IF recognition ended
   THEN restart after a short debounce

IF error = not-allowed OR audio-capture
   THEN mark fatal and stop retrying
IF error = no-speech OR aborted
   THEN treat as normal lifecycle and recover silently
```
