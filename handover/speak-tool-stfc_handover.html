1Project Overview

The Speak Tool reads a warehouse packing station's day of pick-and-pack orders aloud, so the packer's hands and eyes stay on the stock instead of the screen. For each order it speaks: the product's spoken name (from a managed "Names Master Sheet", never the raw marketplace title), its quantity, then the postcode, spelled out, last. The packer says "next" (or presses a button, or a key) to move to the next item.

It exists in two independently-delivered forms that share one set of packing rules:

HTML Speak ToolGoogle Sheets Speak Tool
WhatA self-contained web page dropped onto the day's Order Packing HTML exportGoogle Apps Script bound to each station's own Google Sheet
Where it runsVarmen AIOS hub (speak_tool slug)Six separate station sheets, Extensions → Speak Tool
Shared rules✅ current✅ Unit 3 Lampshade station only

The project began 2026-08-13 as a discovery/root-cause analysis of 160 live feedback items against the (then undocumented) Unit 3 Lampshade Apps Script, and grew into the HTML tool plus a rules upgrade ported onto the Unit 3 Sheets script.

  1. Pack-size table extended. The PACK suffix table in speak_tool_html_sheet_UI/engine.js grew from 12 codes to 29. A new Engine.baseSku() replaced a blanket regex for name lookup — it only strips a suffix it recognises, instead of silently truncating any SKU ending in digits.

  4. Control bar redesign: a QTY/postcode details panel next to the spoken text; the text row wraps instead of truncating; the bar's own height is measured and reserved so the last order scrolls fully into view; Postcode now scrolls to the postcode line.
  5. New regression test — evidence/html-order-details-tests.js — checks all 29 pack codes and re-parses the 13 real pack lists (155 orders) to confirm order count and packing sequence are unchanged. Requires jsdom, not in package.json (§9).
  6. evidence/live-names-tests.js updated to match the engine's internal refactor.

I ran all three Node test suites myself while preparing this handover (after installing jsdom locally, not committed): 28/28, 38/38, and the new suite's assertions all passed — see §9 for the one caveat worth checking before this reaches the hub.

6Current Workflow / Architecture

  • Inside one order, products are re-sequenced by a fixed rank (Rectangle Ceiling Rose → Lampshade → WC cage → Bulb → Ceiling Rose/Other, or a different order without a rectangle rose) — a stable sort. An order with neither a lampshade nor a ceiling rose is untouched.
  • Merge orders are sorted twice: each sub-order internally, then the sub-orders themselves sequenced against each other by ranked contents.
  • Lampshade collections: before an order short on a shade family, the packer collects that family in bulk, up to Engine.MAX_COLLECTION — 10 in the HTML tool, 15 in the Sheets tool (undecided discrepancy, §10).
  • Hold: set an order aside, come back later — HTML tool only.

speak_tool_html_sheet_UI/engine.js is the single source of truth for the rules and is compiled into the HTML tool by build.js. The Sheets tool is not built from this file — packing-priority.gs is a hand-ported, independent re-implementation, and the other five stations have none of it. There is no shared runtime between the two forms; keeping their rules in sync is a manual, human responsibility.

7How to Run

HTML Speak Tool

node packlist_extension/build.js   # rebuilds the bundle + Speak-Tool.html
                                     # ALWAYS run before uploading
  • Drop the day's Order Packing HTML onto packlist_upload/Speak-Tool.html (what the hub serves).
  • Or add <script src="packlist-speak.js"></script> before </body> of the live page, same origin.
  • Or node packlist_extension/add-speak.js <file>.html to inject the tool into a saved pack list.

Voice commands need http(s) — Chrome denies microphone access to file://. node packlist_extension/serve.js <file> serves a file locally for manual testing.

Google Sheets tool

Open the station sheet → Extensions → Apps Script to edit, or use the sheet's own menu: Speak Tool → Run Clean and Merge, then Speak Tool → Speak All Rows.

10Known Issues / Dependencies

HTML Speak Tool

  • "Save a copy" silently fails on the hub (iframe sandbox lacks allow-downloads). Works when the loader is opened directly.
  • Send Order Instruction is not spoken (no field for it on the page). The Sheets tool speaks it.
  • html-order-details-tests.js needs jsdom, absent from package.json.
  • The isMerge trigger-rate discrepancy above (§9) — needs a decision, not yet a confirmed bug.

Unit 3 Sheets tool

  • onOpen defined in both action.gs and cleaned.gs — last loaded wins.
  • Pack-suffix lookup in cleaned.gs strips exactly 3 characters, wrong for a 2-character PK suffix.
  • Merge label still reads "merge order total: N : merge order: 1".
  • Duplicate-postcode blanking also blanks the QR flag as a side-effect.
  • RPR44WH hardcoded in shared cleaning logic.
  • No Hold feature. Collection limit is 15 vs the HTML tool's 10 — undecided.

Other five stations have none of the packing-priority, collection, merge-sequencing or Hold work; rolling it out (or retiring their sheets) is an open decision, not started.

External dependencies

  • Chrome only — SpeechRecognition is Chrome-specific and cloud-backed.
  • Network access to docs.google.com for live names; falls back to built-in names offline.
  • Varmen AIOS hub + Postgres hub_pages table, reached only via a separate repository's push_to_hub.js. HUB_DB_URL is out-of-band, never committed.
  • Google Apps Script platform; clasp CLI optional but recommended.
