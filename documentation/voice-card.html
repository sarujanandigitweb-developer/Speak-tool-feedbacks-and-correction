If it keeps mishearing you

1 — Set your listening accent first

Press ⚙ Voice and set Listening accent. It arrives on English (UK); most packers here get better results on English (India / South Asia). This one setting fixes more than any change of wording. It is remembered, so you only pick it once.

2 — Use two words instead of one

Short single words are the hardest thing for a microphone to place. Set aside is recognised far more reliably than hold, and show held orders beats show hold.

3 — Sound-alikes are already accepted

The tool knows that hold often comes back as gold, old, cold or held, and it treats those as Hold. It will not do this while the tool is speaking, so a shade named Rose Gold can never hold your order by accident.

4 — Check what it actually heard

When a command is not recognised the bar shows Heard “…” — not a command, so you can see whether the microphone caught you at all. For a full list, open the browser console and type STX.misses.

The buttons never fail

Voice is there to keep your hands on the stock. Every command on this card is also a button on the bar, and the arrow keys work too: ← back, → next, ↑ repeat.

One behaviour change, declared

Next no longer loops at the end of the queue. It used to wrap back to the first order forever, because the tool had no idea of being finished. A completion message is impossible without a stopping point, so at the last order the wrap became a stop. Every step before the last order is untouched, and Back keeps its wrap.
